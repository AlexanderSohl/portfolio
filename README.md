# Alexander Sohl Portfolio

A personal portfolio for sharing my background, technical skills, and projects with recruiters and classmates.

**Live site:** [alexandersohl.github.io/portfolio](https://alexandersohl.github.io/portfolio/)

## Pages

- Home: introduction and featured work
- About: programming and education story
- Projects: GOOB, Sect0r, and Unmanned Rover
- Skills: programming, game development, testing, and tools
- Contact: email, GitHub, and a validated contact form

## View locally

Open `index.html` in a web browser. The site uses relative file paths and does not need a server, package installation, or build step.

## Notes and acknowledgments

- Built with plain HTML, CSS, and vanilla JavaScript.
- The Cinzel and Inter typefaces are from Google Fonts.
- Project images and footage are personal project materials provided by Alexander Sohl.
- The web-ready MP4 copies were prepared with FFmpeg.
